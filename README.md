# Limulus

**One experiment. Many universes.**

Limulus is a visual Python workspace for exploring data pipelines and training
configurations through independent execution paths.

Read the [organization overview](profile/README.md) for the project concept,
universe execution model, and links to the VS Code extension and server-hosted
local web interface.

The organization profile lives in `profile/README.md`, with its logo in
`profile/logo.jpg`.
